## Odd Variables

- **YRBUILT**: Looks numeric but is binned decade codes — 1980 means 1980–1989, not literally 1980.
- **UNITSIZE**: Binned square footage, not continuous.
- **HHGRAD**: Ordered education levels but gaps between codes are not meaningful numerically.
- **ROACH**, **FUSEBLOW**, **NUM\*** disability/asthma vars: Ordinal count categories — scale is not linear.
- **PERPOVLVL**: Codes 2–500 are literal percentages; code 1 = "≤0%" and 501 = "501%+" are caps.

### Solutions to the above

Treat as ordinal integer (no changes)
- **YRBUILT**
- **UNITSIZE**
- **HHGRAD**
- **ROACH**
- **FUSEBLOW**
- **NUM\***

Minor fixes (in 01/02/01_...)
- **PERPOVLVL**
  - The values are literal percentages
  - Code 1 and 501 are caps
  - Decide to treat code 1 as 0% and code 501 as 501%
